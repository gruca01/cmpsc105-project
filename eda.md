# EDA Summary

We explored the Open Food Facts dataset using Pandas and Seaborn. We checked data types and missing values, cleaned text labels, and replaced impossible nutrient values with missing values. We also calculated summary statistics and created plots to examine nutritional patterns.

Many products had low sugar content, creating a right-skewed distribution. The sampled scatter plot showed that products with more fat generally had more calories. However, unusual calorie values need further investigation because the full-data correlation did not match the visual pattern.

The main limitations were missing fiber values, unknown food categories, and uneven country representation.
